# StudySync Landing Page<br>

A modern, responsive landing page for **StudySync** – a platform focused on seamless learning for brighter futures. Built with pure HTML and CSS, the layout adapts beautifully to various screen sizes and offers a clean and engaging user interface.<br>

## 💡 Features<br>

- ✅ Fully responsive layout using media queries<br>
- ✅ Attractive hero section with call-to-action buttons<br>
- ✅ Company trust section with logos<br>
- ✅ Highlighted feature cards with colorful designs<br
- ✅ Testimonials with hover effects<br>
- ✅ Newsletter subscription section<br>
- ✅ Footer with quick links and social icons<br>

## 🛠️ Technologies Used<br>

- HTML5<br>
- CSS3 (Custom properties, Flexbox, Grid, Animations)<br>
- Google Fonts (`Inter`)<br>
